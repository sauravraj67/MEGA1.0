# MEGA1.0
<img width="883" height="446" alt="Screenshot 2026-05-15 045541" src="https://github.com/user-attachments/assets/9424896d-61fd-4f76-826c-9b75cfc104b8" />

I am making a cool micro pad for myself it has 8 key switches, one rotor encoder and a 0.91 inch screen. It is based on XIAO RP2040. It has 3 layers which would be controlled by the rotor encoder and the selected layer would be displayed on the screen. I also used Hot-Swap so that i don't have to solder/de-solder the switches while changing it.
## Features

- Based on Xiao Rp2040
- Has HotSnap base
## Firmware
- Firmware is based on QMK.
